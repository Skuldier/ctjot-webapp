{# ------------- Random Pool ------------- #}

Configure the Random (Custom) pool for bucket-list objectives. cjot-beta's built-in Random is fixed at 65% gated quest / 30% non-go boss / 15% recruit — this tab lets you customize that mix. When you pick Random (Custom) in any bucket-list objective slot, the YAML emitter draws from these enabled categories using the weights you set. Disabled categories are excluded entirely.

Weights don't need to sum to 100; cjot-beta normalizes them. Default is equal weight (10) across the random-pull quest, recruit, and boss categories. Specific objectives (rocks, fragments, recruit-N) are off by default — opt in when your seed configuration supports them.
